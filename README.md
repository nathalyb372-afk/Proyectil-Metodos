## Requisitos

Instalar dependencias:

pip install -r requirements.txt

## Ejecutar el programa

python main.py

## Archivos principales

* main.py: punto de entrada
* interfaz.py: interfaz gráfica
* calculos.py: métodos numéricos y ecuaciones
* simulacion.py: animación y simulación con viento

## Funcionalidades

* Interfaz gráfica interactiva
* Validación de entradas
* Métodos numéricos:

  * Bisección
  * Newton-Raphson
* Simulación con ruido blanco
* Animación de trayectorias
* Comparación de convergencia
